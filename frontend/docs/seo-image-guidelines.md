# Vyntics SEO & Image Guidelines

## Purpose

This document defines the SEO and image-handling rules for the Vyntics website.

Any developer or AI coding agent adding or modifying website images must read and follow this document before making changes.

---

## 1. Image Alt Text

Every meaningful image must have descriptive, contextual alt text.

### Good

- "Vyntics cloud architecture and migration services"
- "Data engineering pipeline connecting business systems"
- "Vyntics team collaborating on a technology project"

### Avoid

- "image"
- "image1"
- "photo"
- "banner"
- "cloud"
- Keyword-stuffed descriptions

Alt text should describe what the image communicates, not simply contain SEO keywords.
