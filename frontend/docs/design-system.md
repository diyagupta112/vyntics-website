# Vyntics Public Website - Design System

## Font

- Font family: **DM Sans**

## Colors

| Token | Hex |
|---|---|
| Text | `#0B0B0F` |
| Background | `#FFFFFF` |
| Primary | `#1453DB` |
| Secondary | `#DDDBFF` |
| Accent | `#2563EB` |

## Usage

- Use **Text** for primary text and dark UI elements.
- Use **Background** as the main page/background color.
- Use **Primary** for primary actions and important brand elements.
- Use **Secondary** for supporting backgrounds/highlights.
- Use **Accent** for secondary emphasis and interactive states where appropriate.

## Rules

- Use DM Sans throughout the public website.
- Use the colors above instead of introducing new colors without approval.
- Keep the visual style clean, modern, and consistent across sections.
- Section-specific design decisions belong in `design-guide.md`.
